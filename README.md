# Deliver releases

Installers for the Deliver desktop app, a planner that tells you what to do next. The source code isn't public; this repository only holds the releases and the update manifest (`latest.json`) the installed apps check.

- **Windows:** `Deliver_<version>_x64-setup.exe`
- **Linux:** `Deliver_<version>_amd64.AppImage` (updates itself), or the `.rpm` / `.deb`

Download from [the latest release](https://github.com/RuiLourenco/deliver-releases/releases/latest). Installed apps offer new versions themselves.

Deliver is free to use under its [licence](LICENSE); all rights reserved. Each release includes `THIRD_PARTY_NOTICES.html`, listing the open-source software it contains and their licences.
